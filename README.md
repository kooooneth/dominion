# Dominion

A real-time world-conquest strategy game that runs entirely in the browser — no install, no build step, no server. Mine gold, feed your armies, raise a military, and take over the Earth while rival nations (and the sea) fight back.

**[Play it live](#)** — replace this link with your GitHub Pages URL once it's enabled (see below).

## Features

- **Real-time strategy** — no turns; the world keeps moving. Pause or speed up (1×/2×/3×) any time.
- **4 game modes** — Conquest, Blitz, Regicide, Last Stand
- **6 difficulty levels** — Peaceful → Impossible
- **A big, organic world** — hex-based continents and ~30 islands, procedurally generated every game
- **Full economy** — Gold and Food income, 14 building types (Factory, Farm, Barracks, Fort, Harbor, Missile Silo, Air Defense, Shield, and more)
- **Missiles** — blast radius, cooldown, interceptors, and one-time shields
- **Fog of War** (optional) and dynamic world events (plagues, gold rushes, uprisings)
- **9 languages** — English, Español, Français, Deutsch, Português, Italiano, Русский, 中文, 日本語

## Running it

It's a single self-contained HTML file — just open `index.html` in any modern browser. Nothing to install.

## Tech

Vanilla HTML/CSS/JavaScript, rendered on an HTML5 `<canvas>`. No frameworks, no build step, no dependencies.
